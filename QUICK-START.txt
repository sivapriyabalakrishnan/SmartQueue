📦 INSTALLATION (3 STEPS):

1. EXTRACT FILES
   → Copy entire "smartqueue-rebuilt" folder to:
   → C:\xampp\htdocs\smartqueue

2. SETUP DATABASE
   → Start XAMPP (Apache + MySQL)
   → Open: http://localhost/phpmyadmin
   → Import "database.sql"

3. ACCESS SYSTEM
   → Homepage: http://localhost/smartqueue/
   → Admin: http://localhost/smartqueue/admin.php

🚨 TROUBLESHOOTING:

Problem: Database connection error
Solution: Check MySQL is running, verify db.php credentials

Problem: Page not found
Solution: Ensure files in htdocs/smartqueue/, Apache running

Problem: Login not working
Solution: Import database.sql again, clear browser cache

Problem: Blank page
Solution: Check PHP error logs in XAMPP
